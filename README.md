# Hydrophob Landing

Односторінковий україномовний лендінг бренду Hydrophob — захисні нанопокриття (автохімія, засоби для взуття/одягу, гідрофобізатори для будматеріалів).

## Стек

- PHP (без фреймворків): `index.php` збирає сторінку з секцій у `sections/`
- Ванільні CSS/JS (`css/style.css`, `js/script.js`), Swiper 11 з CDN, Google Fonts (Montserrat)
- Дані в JSON:
  - `products.json` — товари (мультимовні назви/описи UA/RU/EN, атрибути, повні описи, фото)
  - `strings.json` — усі текстові рядки інтерфейсу по секціях у 3 мовах
  - `images.json` — медіа секцій (hero, галерея, infoBlock, reviews)

## Функціонал

- Каталог-слайдер з попапом «Детальніше» (опис і характеристики товару)
- Кошик з майстром оформлення (кількість, суми, localStorage)
- Перемикач мов UA/RU/EN без перезавантаження
- Анкорна навігація, відео-попапи, анімації появи (друкування/fade)

## Запуск локально

Потрібен будь-який PHP-сервер, наприклад:

```bash
php -S localhost:8080
```

Google Maps на сторінці контактів потребує ключа API — замініть `API_HERE` у `index.php`.
